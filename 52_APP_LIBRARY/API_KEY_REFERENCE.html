52-App Library — Configuration Reference

API keys you'll need

Every third-party API key, token, or credential each app can use, checked against that project's own docs — not guessed. Required vs. optional, per app, with the exact environment variable and what it unlocks.

Compiled 2026-09-20 from each app's own README, docs site, or shipped .env.example — six parallel research passes, one per batch of apps, each independently sourced. “Required” marks a key the app's own docs call necessary for its core or production use (a few are conditional — e.g. unless you run a local LLM instead). Everything else is an optional integration: the app runs fully without it.
