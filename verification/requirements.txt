# (Python 3.9+; developed and proven against 3.11.15) -- everything below
# is needed only to (a) run the real Flask apps the builder assembles and
# (b) run the real Playwright browser check.
#
# Install offline, from the vendored wheels in this directory (no network
# required for the Python side):
#   python3 -m pip install --no-index --find-links=verification/vendor/wheels -r verification/requirements.txt
#
# Or online, from PyPI (works on any platform/Python version, not just the
# one the vendored wheels were built for):
#   python3 -m pip install -r verification/requirements.txt
#
# Either way, one further step is unavoidable and is NOT satisfied by this
# file: Playwright's Python package (below) does not include an actual
# browser binary. See verification/README.md for that step and for the
# fully-offline "bring your own Chromium" alternative.
